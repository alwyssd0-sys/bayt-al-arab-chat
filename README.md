# Bayt Al-Arab Chat

نسخة مبسطة من مشروع شات يعمل بالذكاء الاصطناعي (يدعم نصاً وصوراً) — هذا الفرع يضيف README وتعليمات إعداد وتشغيل MVP.

## لماذا هذا المشروع مفيد
- يتيح للمطورين تشغيل نسخة محلية من شات قائم على OpenAI Assistants API مع دعم للصور (`purpose=vision`).
- مناسب كنقطة بداية لبناء واجهة محادثة، بوت للدعم، أو خدمة تحليل صور + نص.
- يساعد على تنظيم الشات وتطويره مع إدارة صلاحيات الأعضاء والمشرفين.

## المتطلبات
- Node.js 18+ (موصى)
- حساب OpenAI مع صلاحيات الوصول إلى Assistants API وFiles API

## المتغيرات المطلوبة
أنشئ ملف `.env` بناءً على `.env.example` وتأكد من وجود القيم التالية:
- `OPENAI_API_KEY` — مفتاح OpenAI (لا تضعه في الكود أو الواجهة)  
- `ASSISTANT_ID` — معرّف المساعد (assistant) في OpenAI  
- `THREAD_ID` — معرّف الـ thread الذي ستتبادل فيه الرسائل  
- `PORT` (اختياري) — المنفذ المحلي للخادم (الافتراضي: 4000)

## تشغيل محلي
1. انسخ المستودع واجه الفرع `feat/openai-vision-chat` أو دمج الملفات المطلوبة.
2. أنشئ ملف `.env` واملأ القيم.
3. ثبّت الحزم:
   ```bash
   npm install
   ```
4. شغّل الخادم:
   ```bash
   node server.js
   ```
5. افتح الواجهة البسيطة أو أي واجهة فرونت مناسبة.

## اختبار endpoints (أمثلة curl)
- اختبار رفع ملف إلى OpenAI مباشرة (يتحقق من صلاحية المفتاح):
  ```bash
  curl -v -H "Authorization: Bearer $OPENAI_API_KEY" \
    -F "file=@/path/to/test.jpg" -F "purpose=vision" https://api.openai.com/v1/files
  ```
- اختبار endpoint المحلي (يرفع صورة ويبدأ run):
  ```bash
  curl -v -F "text=مرحبا" -F "image=@/path/to/test.jpg" http://localhost:4000/api/chat
  ```

## مشاكل شائعة وحلول سريعة
- `401 Unauthorized`: تحقق من `OPENAI_API_KEY` وصلاحياته.
- `404 Thread/Assistant not found`: تأكد من `ASSISTANT_ID` و`THREAD_ID` وأنهما يتبعان نفس الحساب.
- `413 Payload Too Large`: قلل من حجم الصورة أو اضبط حد التحميل في الخادم.
- `CORS`: استخدم الخادم كـ proxy بدلاً من إرسال الطلبات مباشرة إلى OpenAI من المتصفح.

## الأمان
- لا تضع مفاتيح API في الواجهة أو في المستودع.
- استخدم GitHub Secrets أو متغيرات بيئة على الخادم عند النشر.
